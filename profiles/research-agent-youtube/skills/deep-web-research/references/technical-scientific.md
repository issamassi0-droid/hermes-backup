# Technical/Scientific — Special Rules

## Application Principle
Scientific/medical inquiries requiring source hierarchy precision.

## Precise Rules

1. **Hierarchy**:
   - Peer-reviewed paper (RCT > systematic review > observational study)
   - Official institution (WHO, NIH, FDA...)
   - Media coverage (last resort, for context only)
2. **Publication year is critical** in fast-evolving fields (AI, genomics).
3. **Distinguish between**: scientific consensus / preliminary result / hypothesis.
4. **Do not cite secondary aggregators** when the primary source is available.
5. **Medical warning**: Anything touching diagnosis/dosage requires an explicit note to consult a specialist.
