# Multi-Entity Comparison — Special Rules

## Application Principle
Comparison between two or more entities (products, companies, countries, people).

## Precise Rules

1. **Mandatory unified criteria**: Do not start searching before defining them. If the user has not defined them, propose 3-4 criteria and ask.
2. **Same source for both sides**: Do not compare Company A from an official report with Company B from a blog.
3. **Unified time period**: Compare 2024 with 2024, not 2024 with 2022.
4. **Weight, not count**: Do not win by majority of criteria, but clarify which criterion matters most for the user's purpose.
5. **Disclose absence**: If you cannot find data for an entity on a criterion, state it explicitly instead of ignoring it.
