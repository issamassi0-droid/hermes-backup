# Contested Topics — Special Rules

## Application Principle
Only invoked when the topic is politically, health-wise, or scientifically controversial.

## Precise Rules (exceptions, not repetition of the general framework)

1. **Deliberate balance** — cross-checking sources from the same angle is not enough. Fetch at least two sources from opposing positions on the spectrum.
2. **No silent favoritism** — if trusted sources conflict, present both positions.
3. **Distinguish between**: (a) genuine scientific disagreement, (b) political disagreement, (c) denial of consensus. Each type requires different handling.
4. **Descriptive language** — avoid "the truth is...", use "Group X argues...".
5. **Upper limit**: 3 sources per position, otherwise the search turns into amplification.
