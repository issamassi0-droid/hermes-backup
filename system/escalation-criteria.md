# Escalation Criteria

Explicit triggers for the human gate. Once "critical" is a checklist, not a vibe.

---

## Auto-Escalate Triggers

The following automatically route to the human gate:

| Trigger | Reason |
|---|---|
| Any Publisher action | External, irreversible by definition |
| Any spend/resource use above threshold | Resource protection |
| Any Class 3 amendment | Already required |
| Any Bot-Maker grant beyond read-only | Already required by Fix 4 |
| Editor-QA factual_error_rate > 15% | Quality breach |
| Architect confidence < 0.4 | Uncertain orchestration |
| Group room turns ≥ 8 | Loop prevention |
| Any destructive command | Irreversibility |
